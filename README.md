XeLauncher is a Launcher and config editor for [xenia](https://xenia.jp/) (canary), xenia lacks a launcher and editor like [RPCS3](https://rpcs3.net/) and [PPSSPP](https://www.ppsspp.org/) do. So I decided to make one!
This is a Dear ImGUI project made with C++ and, well boredom I guess. lol
